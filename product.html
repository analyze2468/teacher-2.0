答题模块（重点）

答题有两种模式：填自己的 API Key，体验拉满；不填也能练，基础功能都在。

  • ✅ 填 Key：语音、计时、录音、上传图片、AI 细评分、自由追问
  • 🟡 不填 Key：基础练习、计时录音都在；不能传图，追问只给固定问题
  • · 练完自动进「练习记录」，作答和考官点评都能回看

答题模块（重点）：两种模式怎么选

  1. 1

    ✅ 填入你自己的 API Key（体验拉满）

    语音答题、计时器、录音都有；录音用来回放自己的作答，方便复盘。支持上传图片作答；用你的大模型打分，评分细节更丰富。

  2. 2

    🟡 不填 API Key 也能用

    基础练习、计时录音都保留。限制：不能上传图片；追问只能给固定的标准化问题，不能自由闲聊。

  3. 3

    📝 评分后：追问 + 留档

    点「AI 追问」跳到独立页面，自动带上这道题、你的作答和评分；填了 Key 可以自由聊、想问啥就问啥，没填就给固定问题。每次练习也会自动存进「练习记录」。

亮点收尾

  • 考场感很强 · 题干、计时、录音都在一屏，坐下就能进入状态。
  • 答题 + 考官互动 · 不是只给一个分数，还能顺着追问继续聊，像真考官坐在对面。
  • 反馈更丰富 · 维度得分、整体解析、改进建议都有，比线下考官当场说的更丰富。
  • 记录留得住 · 每次答题和点评自动进练习记录，只存在本机浏览器。
