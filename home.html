答题模块：两种模式

  1. ✅ 填自己的 API Key：语音答题、计时、录音、图片作答、AI 细评分都有；评分后去「AI 追问」自由聊。
  2. 🟡 不填也能用：基础练习、计时录音保留；不能传图，追问只给固定的标准化问题。
  3. 📝 练完自动留档：每次评分进「练习记录」，回看作答和考官点评，也能重做。
重点就是考场感很强：题干、计时、录音、评分、追问连在一个流程里。填了自己的 API Key，体验更满（图片作答、更细的 AI 评分、自由追问）；不填也能练，只是不能传图、追问只给固定问题。Key 只存在本机浏览器。
